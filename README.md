# SRW 汉化补丁与工具

本仓库提供《超级机器人大战》系列（WonderSwan / WonderSwan Color）的汉化补丁与构建工具。

## 项目

- [compact3/](compact3/) — **超级机器人大战 COMPACT3**（WSC）汉化
  - 补丁页面：双击 `compact3/index.html`，拖入原版日文 ROM，校验通过后本地打补丁（不上传、不联网）
  - 构建：`python build.py -i 原版.wsc -o 输出.wsc`，详见 [compact3/README.md](compact3/README.md)

## 使用须知

- 仓库只包含补丁与工具，**不提供游戏 ROM**。
- 补丁仅供自己游玩，**禁止分发汉化后的 ROM**。
- 请使用自己拥有的正版原版 ROM。
