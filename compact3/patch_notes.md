# 指针补丁说明（非文本字节改动）

`text.xlsx` 的「指针补丁」表目前 **11 行**。这张表只放**非文本**的字节级改动：布局坐标、窗口清屏范围、固定提示指针，以及少量补位字节。

文字本身不在这张表里：中文由构建时按工作簿动态编码（汉字码位按 Unicode 排序现场分配）；文本指针由「UI文本」的「指针表地址 / 立即数」列自动回写并校验。

构建在处理完所有文本后会逐行核对「原字节」，一致才写入「新字节」；任何一处对不上都会直接报错，避免 ROM 版本不符时静默改错。

## 分类说明

**布局坐标（第 1、10 行）**
只改屏幕上的 x 坐标，让读档/存档表头的「关卡」列避开左边的「已过」字样；不涉及任何文字编码。

**演示窗口（第 5–9 行）**
配置菜单里「デモ（演示）」开关的状态文字定位与清屏范围：
- `0x763E0D / 0x763E11`：状态文字定位到 `0x0E60`，紧接标签；
- `0x7741DB / 0x7741DC`：清屏起点 `0x1CC0`；
- `0x7741E0`：清屏宽度 `0x80`，到字段右边界 `0x1D40`。

**固定指针（第 3、4 行）**
名字输入界面的假名提示，固定指向原版的平假名行 `0xB00C`；与中文码表无关，因此不随码位分配变化。

**补位（第 2、11 行）**
把空白补成 `FF`，用于消除菜单网格与「反击 / L3」之间多出来的空格。

## 为什么不做成自动生成

这 11 行都是**布局常数、固定指针或补位值**，不是字符码，也不是文本指针：
- 字符码由编码器按工作簿动态生成；
- 文本指针由「指针表地址 / 立即数」自动回写；
- 只有这类无法从文本推导的字节，才集中放在「指针补丁」表，便于逐条核对。

新增改动时请按此原则归类：凡是与文字或文字指针有关的，都不要写进这张表。
